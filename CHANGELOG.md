# Changelog

## v0.1.2

* New features
  * Support ANSI escape sequences for clearing the screen and clearing a line.
    The implementation is rudimentary, but makes it possible to start over at
    the top and have horizontal animation.

## v0.1.1

Switch the the `egd_fhunleth` fork of `egd` for Unicode fixes. This
also changes the default font to Terminus16.

## v0.1.0

Initial release
